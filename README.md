# 💊 MediSearch - Medicine Details Finder

A responsive web app that provides detailed information about any medicine using the **OpenFDA Drug Label API** — completely free, no API key required.

## Features
- Search any medicine by brand or generic name
- Displays: Purpose, Dosage, Warnings, Side Effects, Contraindications, Precautions, Storage, Manufacturer
- Clean card-based UI with color-coded sections
- No API key needed

## How to Use
1. Clone or download this repository
2. Open `index.html` in your browser
3. Type any medicine name (e.g. `Ibuprofen`, `Aspirin`, `Amoxicillin`) and press Search

## API Used
- [OpenFDA Drug Label API](https://open.fda.gov/apis/drug/label/) — Free & public, no authentication needed
